# AnimaFelis 🐾

A PixelArt mobile game focused on emotional well-being and virtual pet care.
Currently in design and pre-development phase (Final Year Project).

## Concept
Players raise a cat spirit's egg through daily emotional interactions —
mood logging, journaling, and storytelling. The pet responds to care and neglect,
creating a gentle emotional accountability loop.

## Planned Features
- Personality-based egg & pet customisation
- Emoji mood logging + daily reflection prompts
- Step count integration for pet exploration
- Pixel farming & baking mini-games
- Weekly habit & mood dashboard

## Tech Stack (Planned)
- Platform: Android (mobile)
- Language: Java / Kotlin
- Art Style: 2D Pixel Art
